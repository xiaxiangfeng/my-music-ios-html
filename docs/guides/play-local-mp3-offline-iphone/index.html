How to Play Local MP3 Files Offline on iPhone

With VinylPocket, you can import MP3 files from the Files app and play them offline on your iPhone. The app keeps its own copy of each imported track, so you can listen without a connection to iCloud Drive. You’ll need an iPhone running iOS 18 or later and MP3 files of your own.

Import MP3 files from Files or iCloud Drive

  1. Make sure the MP3s appear in the iPhone’s Files app.
  2. In VinylPocket, open VINYL MODE and tap Import Music Files.
  3. In the file picker, choose On My iPhone for files already on the device, or iCloud Drive for files you’ve saved there. If a file is only in iCloud, stay online until the import finishes.
  4. Open Record Collection and select one of the imported tracks to play it. Your original MP3s stay where you saved them.

Listen offline and use Lock Screen controls

Once a track appears in Record Collection, try opening it with Wi-Fi and cellular data off. Start playback, then lock your iPhone. The music continues and you can pause or resume it from the Lock Screen.

Imported MP3s are stored separately from the cloud cache. Clear Cloud Cache removes downloaded copies of remote tracks and leaves imported MP3s available.

If you can’t find or import a song

Open the MP3 in Files to check that the file is available. If it lives in iCloud Drive, connect to the internet and try importing again. VinylPocket needs an audio file that Files can open. Downloads that stay inside a streaming app’s library aren’t available to the file picker.

If your collection is on a NAS, follow the WebDAV music setup guide to add tracks and cache them before going offline.
